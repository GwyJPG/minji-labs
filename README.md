# Minji Labs

Sitio web oficial de Minji Labs — Desarrollo web moderno, landing pages de alta velocidad y soporte continuo en Lima, Perú.

## Tecnologías

- **Framework**: [Astro](https://astro.build/) (v5)
- **Tipografías**: Poppins & Inter
- **Estilos**: Vanilla CSS con variables de diseño, glassmorphism y arquitectura responsiva.

## Estructura del Proyecto

```text
/
├── public/
│   ├── images/
│   └── logo.png
├── src/
│   ├── components/
│   ├── layouts/
│   ├── pages/
│   └── styles/
│       └── global.css
├── astro.config.mjs
└── package.json
```

## Desarrollo Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build

# Previsualizar build de producción
npm run preview
```
